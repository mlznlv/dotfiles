# Roadmap

## v0.1

- Stable YAML v1 schema.
- Safe `init`, `check`, `diff`, `apply`, and `status` workflows.
- Atomic generated-state replacement.
- macOS and Linux releases for amd64 and arm64.

## v0.2

- `doctor` diagnostics.
- Explicit rollback command.
- Better conflict reporting for adopted Zsh configurations.

## v1.0

- Compatibility commitment for YAML v1.
- Documented migration policy.
- Reproducible signed releases and SBOMs.

Out of scope: package installation, remote script execution, dynamic plugins, and automatic conflict resolution.
